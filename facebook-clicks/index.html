Facebook click prediction: trees plus logistic regression

Concept

Start from the logistic click model. A linear model needs useful inputs; it cannot invent every joint pattern from individual indicators alone. A decision tree asks a sequence of feature questions. Reaching a leaf identifies a region of feature combinations rather than one input in isolation.

He et al. combine boosted decision trees with logistic regression: encode reached leaves as sparse indicators, then use them as inputs to the probabilistic model. The paper also studies practical choices involving features, freshness, sampling, and calibration. Its model is a click-prediction stage, not an ANN retriever. Paper and author PDF, ADKDD 2014.

Architecture

Each example reaches one leaf in each tree. A separate coefficient can be learned for each tree/leaf indicator. Those transformed features allow a simple final model to use patterns discovered by a nonlinear preprocessing stage.

Worked example

Imagine one toy tree asks “hiking interest?” then “hiking category?” It sends a matching pair to leaf 3. A second tree asks “recent exposure count > 4?” and sends the row to leaf 1. With four leaves per tree, the transformed row is:

tree 1 indicators: [0, 0, 0, 1]
tree 2 indicators: [0, 1, 0, 0]
combined input:   [0, 0, 0, 1, 0, 1, 0, 0]

If the active leaf coefficients are 0.8 and -0.4 and the bias is -2, the final logit is -1.6. Its sigmoid is about 0.168. These invented values illustrate how tree paths become inputs; they are not learned results from the paper.

Implementation exercise

Create a synthetic binary-label table with a known interaction. Fit a small boosted tree model, extract leaf IDs, one-hot encode them, then train a logistic head. Compare against logistic regression on raw indicators and the tree model alone. Reserve future data before fitting preprocessing or tuning.

Keep the learned tree structure and leaf encoder version with the logistic head. Replacing the trees can change the meaning of every column. If sampling nonclicks, document how serving probabilities will be recovered or calibrated.

Check your understanding

Explain why leaf 3 of tree 1 must be a different input from leaf 3 of tree 2. Then explain why a model with excellent ordering can still misestimate click counts.
