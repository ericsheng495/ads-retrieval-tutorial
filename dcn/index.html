DCN: learn explicit feature crosses

Concept

Manual crosses require choosing combinations in advance. A cross network repeatedly combines its original input with its evolving representation. DCN places that branch alongside a conventional deep network.

In the original cross layer, with column-vector notation:

x_next = x0 * dot(w, x_current) + b + x_current

x0 is the original concatenated feature/embedding vector, w is learned, and the dot product is a scalar. Multiplying the original coordinates by that scalar introduces products between input coordinates. Repeated layers construct bounded-degree interactions; a residual addition retains the previous representation. Wang et al., 2017.

Architecture

The cross and deep representations feed a final prediction head. “Cross” here means feature multiplication, not cross-validation or a transformer cross-attention layer.

Worked example

Use invented numbers x0=x_current=[1,2], w=[0.5,0.25], and b=[0,0]. The scalar dot product is 0.5*1 + 0.25*2 = 1. Therefore:

x_next = [1,2] * 1 + [0,0] + [1,2] = [2,4]

To see the interaction, expand the first coordinate symbolically: x01*(w1*x01 + w2*x02) + b1 + x01. The term w2*x01*x02 is an explicit pair interaction. The numbers alone hide that structure; the expansion exposes it.

Implementation exercise

Write a PyTorch layer taking [batch, d] tensors. Compute a [batch, 1] scalar projection, broadcast its product with x0, then add bias and residual. Verify the example by hand. Stack two layers while passing the same x0 to both. Compare an MLP, a cross-only model, and their combination on the same synthetic task.

Do not accidentally replace the scalar with an unrestricted matrix layer; that changes the original architecture toward DCN V2. Track training cost and validation loss rather than assuming more cross layers improve a sparse dataset.
