# Retrieval Lab

An interactive guide to ML candidate retrieval: nine concept-first lessons,
live SVG diagrams, worked examples, implementation exercises, and research papers.

**Read the site: https://ericsheng495.github.io/ads-retrieval-tutorial/**

This repository contains the generated public website. Its GitHub Pages workflow
publishes updates on pushes to main. The project source and Markdown lessons are
maintained separately in `ericsheng495/ads-retrieval-from-scratch`.

Progress and checklist state stay in your browser. There are no accounts,
analytics, remote progress records, external runtime scripts, or API keys.

To preview these static files: `python3 -m http.server 4173`.
