PLE: separate task-specific and shared knowledge

Concept

Flexible sharing can still mix signals that should remain task-specific. PLE organizes task-specific experts and shared experts into extraction layers, with gates controlling which representations flow upward. Stacking these layers progressively separates and refines the knowledge used by different tasks.

A task gate combines that task's experts with shared experts. A shared gate at an intermediate extraction layer can combine information from all expert groups. This is a more structured sharing arrangement than MMoE's common expert pool; it addresses negative transfer and uneven task tradeoffs without guaranteeing that they disappear on every dataset. Tang et al., RecSys 2020.

Architecture

The diagram is one extraction stage; progressive layering repeats the routing with the prior stage's task/shared representations. A single-stage demonstration is a building block, not a reproduction of the full layered model.

Worked example

Suppose task-A-specific output is [2,0], shared output [1,1], and task-B-specific output [0,2]. An A gate with weights [0.75,0.25] on A/shared produces [1.75,0.25]. A B gate with [0.25,0.75] on B/shared produces [0.75,1.25].

The A gate does not directly mix B's task-specific expert output in this stage. Shared paths can still carry information between tasks. “Task-specific” does not mean the entire network is isolated or that its gradient can never be indirectly affected through shared components.

Implementation exercise

First implement one extraction layer with an explicit list of legal expert inputs for each gate. Verify the toy outputs and test that the A gate's list does not include B-specific experts. Then stack two extraction layers with compatible widths and add task heads.

Compare with shared-bottom and MMoE using the same task definitions and masks. Log task-specific loss curves and parameter counts. Handle task imbalance and missing labels before interpreting a joint-model improvement. Do not claim MovieLens has real ad click and conversion targets.

Check your understanding

What changes between one extraction stage and a progressive stack? Which expert groups can each gate use? Why can “task A improved, task B worsened” matter even if an aggregate score increased?
