Reading guide

New to recommendation systems? Start with foundations and ranking from scratch. The Snap reference learning path explains all ten references from the engineering post with original schematics, worked examples, and implementation exercises. They are included in the 26-entry manifest and bibliography.

Read for one implementation decision at a time. These are supporting references, not claims that our small reference reproduces the papers' full systems. manifest.json has citations, phase mappings, and direct PDF URLs; references.bib is importable into a citation manager.

python scripts/download_papers.py

The downloader validates PDF headers, caches files in papers/pdfs/, records SHA-256 hashes in downloads.json, and reports failures explicitly. PDFs remain local; original author/publisher links and the downloader are versioned. Original copyrights and source-specific terms apply. DSSM, Airbnb, and MF have source/DOI links rather than automatic PDF downloads. Microsoft's currently linked DSSM PDF is a talk deck, so it is not mislabeled as the full paper here.

Read first: Snap's public context

Machine Learning for Snapchat Ad Ranking (Snap Engineering, February 11, 2022). Phase 0 and 7. Use the post to understand eligibility, candidate generation, heavy models, auction, and feedback. It is a dated public description; verify present team-specific architecture during onboarding.

Core reading order

  1. Covington, Adams, Sargin — Deep Neural Networks for YouTube Recommendations (RecSys 2016). Source · PDF · DOI 10.1145/2959100.2959190. Phases 0–1, 6. Read for separating candidate generation from ranking. Exercise: draw where offline item-vector computation saves serving work.

  2. Huang et al. — Learning Deep Structured Semantic Models for Web Search using Clickthrough Data (CIKM 2013). Microsoft source · DOI 10.1145/2505515.2505665. Phase 1. Read for a shared semantic space and query/document encoders. Exercise: distinguish its text features from our ID embeddings.

  3. Yi et al. — Sampling-Bias-Corrected Neural Modeling for Large Corpus Item Recommendations (RecSys 2019). Source · PDF · DOI 10.1145/3298689.3346996. Phase 4. Read for the candidate sampling distribution. Exercise: derive your sampler's correction before coding it; separate sampling bias from exposure bias.

  4. Yang et al. — Mixed Negative Sampling for Learning Two-tower Neural Networks in Recommendations (WWW Companion 2020). Source · PDF · DOI 10.1145/3366424.3386195. Phase 4. Read for combining batch and uniform negatives. Exercise: compare mixtures at a fixed total negative budget.

  5. Jui-Ting Huang et al. — Embedding-based Retrieval in Facebook Search (KDD 2020). Source · PDF · DOI 10.1145/3394486.3403305. Phases 4, 6. Read for end-to-end retrieval modeling and serving tradeoffs. Exercise: identify model and index choices that must be evaluated jointly.

  6. Johnson, Douze, Jégou — Billion-scale Similarity Search with GPUs (IEEE Transactions on Big Data 2019; preprint 2017). Source · PDF · DOI 10.1109/TBDATA.2019.2921572. Phase 3. Read for scalable vector search. Exercise: compare Flat with IVF; our CPU lab does not reproduce the paper's GPU performance.

  7. Guo et al. — Accelerating Large-Scale Inference with Anisotropic Vector Quantization (ICML 2020). Source · PDF. Phase 3 extension. Read for quantization objectives aligned with inner product. Exercise: explain why vector reconstruction error need not preserve top-K.

  8. Kang, McAuley — Self-Attentive Sequential Recommendation (ICDM 2018). Source · PDF. Phase 5. Read for causal history modeling. Exercise: compare causal attention against mean pooling on the same histories.

  9. Grbovic, Cheng — Real-time Personalization using Embeddings for Search Ranking at Airbnb (KDD 2018). Conference source · Airbnb publication index · DOI 10.1145/3219819.3219885. Phase 5. Read for embeddings from marketplace behavior. Exercise: identify what short-term intent an ID-only user tower misses.

  10. Schnabel et al. — Recommendations as Treatments: Debiasing Learning and Evaluation (ICML 2016). Source · PDF. Phases 2, 7; read early when auditing evaluation. Exercise: explain what propensity information would be needed before claiming unbiased offline estimates.

The core sequence follows your PDF. You can read FAISS/HNSW before negative sampling to match the implementation schedule. Papers are not strict prerequisites for each other. Read the relevant method and evaluation sections when a task needs them.
